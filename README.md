
# HelloAgents 第八章配套讲解材料（Memory 与 RAG）
本文件夹包含 [HelloAgents](https://github.com/datawhalechina/Hello-Agents) 课程**第八章：记忆与检索增强**讲解视频的配套讲解网页（HTML 幻灯片）与 PDF 讲义。
## 📁 目录结构
```
HelloAgents-Memeory-HTML/
├── README.md                          # 本说明文件

│   ├── 8.1从认知科学到智能体记忆.html     # 8.1 记忆的理论基础

│   ├── 8.2记忆系统的搭建.html           # 8.2 记忆系统的工程实现
│   ├── 8.3RAG系统.html                 # 8.3 检索增强生成（RAG）
│   └── 8.4智能文档问答助手案例.html      # 8.4 综合案例实战
└── PDF/                               # PDF 版讲义（适合打印与离线阅读）
    ├── 8.1从认知科学到智能体记忆.pdf

```
## 📖 章节内容概览
|     |     |     |
| --- | --- | --- |
| 小节 | 主题 | 内容简介 |
| 8.1 | 从认知科学到智能体记忆 | 从人类记忆的认知科学原理出发，介绍智能体记忆的分类（短期/长期/工作记忆等）与设计思路 |
| 8.2 | 记忆系统的搭建 | 讲解如何使用 `hello_agents` 框架搭建智能体记忆系统，覆盖记忆的存储、检索与管理机制 |
| 8.3 | RAG 系统 | 讲解检索增强生成（RAG）的核心流程：文档加载、切分、向量化、检索与生成 |
| 8.4 | 智能文档问答助手案例 | 综合运用记忆与 RAG 能力，手把手构建一个完整的智能文档问答助手 |
## 🖥️ 使用方式
### HTML 网页版（推荐配合视频观看）
1. 直接用浏览器打开 `HTML/` 目录下对应的 `.html` 文件即可，无需本地服务器。
2. 网页为全屏幻灯片形式，操作方式：
    - → / PageDown / 空格：下一页
    - ← / PageUp：上一页
    - 部分页面支持点击交互
3. 页面加载了 Google Fonts 在线字体，首次打开建议联网以获得最佳显示效果。
### PDF 版
`PDF/` 目录下为各小节的 PDF 讲义，与 HTML 网页内容对应，适合打印、批注和离线阅读。
